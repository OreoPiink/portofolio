# Portofolio Fahrid Purba Astria Saputra

Situs portofolio statis, responsif untuk laptop dan ponsel, tanpa framework atau dependensi tambahan.

## Membuka di laptop

Buka `index.html` di browser. Seluruh tampilan utama dapat digunakan tanpa koneksi internet.

## Menampilkan CV

File CV disimpan di `assets/cv-fahrid-purba.pdf` dan diunduh melalui tombol **Unduh CV**.

## Publikasi melalui GitHub Pages

1. Buat repository GitHub baru dan unggah semua file serta folder proyek ini.
2. Buka **Settings → Pages** pada repository.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
5. Setelah proses publikasi selesai, situs akan tersedia di alamat GitHub Pages repository tersebut.

Sebelum menjadikan repository publik, tinjau kembali informasi kontak yang tampil di situs dan di dalam PDF CV.
